今日最大收获

**Dedekind分割**

将有理数集拆为两个非空集A和A'

若满足:①任一有理数,在且仅在其一 ②集A内任一数小于集A'内任一数

称为分划A|A',A称为下组,A'称为上组.

分划一共可能有四种

其中同时有最值的情况由有理数的稠密性pass

所以可能的还有三种

再把其中有最值的合并为一种且约定最值在上组取

所以可能的就只有两种了:要么有最值,要么没有最值.

将有最值的分划定义为有理数,没有最值的定义为无理数.

由此我们定义实数,且认为实数是完备的,分划意义上的完备.

有些书认为完备的意思是确界原理:实数集上任何有上界的非空子集必有上确界(这里的非空子集就对应了我们的下组,总有那么一个实数充当那个界限,原本无最值的分划由于我们把这种情况的界限定义为无理数并归为实数,所以我们就满足确界原理了)

反过来,按照此处完备的意思,我们立马也能认为有理数集是不完备的,就是上面那种没有最值的分划.

总的来说,戴德金分割只是给实数一个借口,或者说人类还是太渺小了.
